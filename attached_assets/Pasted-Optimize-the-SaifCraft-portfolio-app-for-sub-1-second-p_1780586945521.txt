Optimize the SaifCraft portfolio app for sub-1-second page loads. 
Implement ALL of the following changes:

1. FRAMER MOTION — LazyMotion swap
   - In vite.config.ts, add framer-motion to manualChunks so 
     "vendor-motion" only contains the deferred feature package.
   - In every component that uses `motion.*`, replace:
       import { motion } from "framer-motion"
     with:
       import { LazyMotion, domAnimation, m } from "framer-motion"
     Wrap the root layout (or App.tsx) in:
       <LazyMotion features={domAnimation} strict>
     Replace all <motion.div> → <m.div>, <motion.h1> → <m.h1>, etc.

2. FIREBASE — Lazy initialization + firestore/lite
   - In src/lib/firebase/firestore.ts, change all read-only 
     Firestore calls (getDoc, getDocs, query, collection) to use:
       import { ... } from "firebase/firestore/lite"
     Keep the full "firebase/firestore" import ONLY for onSnapshot 
     real-time listeners, and wrap those in a dynamic import:
       const { onSnapshot } = await import("firebase/firestore")
   - In src/lib/firebase/config.ts, change auth initialization:
       import { initializeAuth, inMemoryPersistence } from "firebase/auth"
       export const auth = initializeAuth(app, { 
         persistence: inMemoryPersistence 
       })
     This prevents IndexedDB persistence code from bundling unless needed.
   - In vite.config.ts manualChunks, split Firebase further:
       "vendor-firebase-app": ["firebase/app"],
       "vendor-firebase-auth": ["firebase/auth"],
       "vendor-firebase-firestore": ["firebase/firestore/lite"]

3. CLOUDINARY — Auto format + quality
   - In src/lib/cloudinary.ts, create a helper function:
       export function optimizeCloudinaryUrl(url: string): string {
         if (!url?.includes("res.cloudinary.com")) return url;
         return url.replace("/upload/", "/upload/f_auto,q_auto,w_auto/");
       }
   - In every component that renders a Cloudinary image 
     (ProjectCard, etc.), wrap the src with optimizeCloudinaryUrl().

4. TANSTACK REACT QUERY — Global staleTime
   - In src/lib/queryClient.ts (or wherever QueryClient is created), 
     set global defaults:
       new QueryClient({
         defaultOptions: {
           queries: {
             staleTime: 5 * 60 * 1000,   // 5 minutes
             gcTime: 10 * 60 * 1000,      // 10 minutes
             retry: 1,
             refetchOnWindowFocus: false,
           }
         }
       })

5. RESOURCE HINTS — index.html preconnect + preload
   - Add to the <head> of index.html:

       <link rel="preconnect" href="https://firestore.googleapis.com" crossorigin>
       <link rel="preconnect" href="https://identitytoolkit.googleapis.com" crossorigin>
       <link rel="dns-prefetch" href="https://www.googleapis.com">

   - If there is a hero/banner image, add:
       <link rel="preload" as="image" fetchpriority="high" href="[hero-image-url]">

   - In index.html or any CSS that loads Google Fonts, append 
     &display=optional to the font URL query string.
   - In any @font-face declarations in CSS files, set:
       font-display: optional;
